# 豆瓣榜单类型技法（Douban Genre Craft）

## Overview

把豆瓣阅读畅销榜单成功作品的**可迁移写作技法**（思想/方法层）用于**原创**类型小说。技法来自真实榜单采集与三本代表作公开简介的三角验证，证据见 `references/techniques.md`。12 transferable craft techniques for original Chinese genre fiction, triangulated from real Douban Read bestseller rankings; see `docs/README_EN.md` at repo root for the English guide.

## 版权边界（先于一切）

- **只迁移技法**：结构、视角、钩子机制、人设逻辑、标题策略属思想/方法层，可自由用于原创。
- **绝不复制**：榜单作品的受保护文字表达、人物姓名、情节细节、独有设定一律不得抄入原创。简介只作技法分析证据，不作改写底本。
- **可逐字引用的例外**：用户自有稿与公版底本——这两类不受此限。
- 写原创时若发现某句/某人/某事直接来自榜单作品，立即替换为原创等价物。

## 十二条可迁移技法

按功能分四组。每条括号内为榜单证据来源（详见 references/techniques.md）。

**开局与钩子**
1. 开局即反常：第一幕抛出奇案/绝境/反常物证，冷开局不上背景铺垫。（大梁仵作剥皮案；风吹草动爆仓清零）
2. 高概念贯穿钩：一个反常物证或 premise 贯穿全书，持续制造好奇。（跨越千年的指纹）
3. 重复修辞成钩：关键句复沓成记忆点与节奏钩。（"不能再出轨"×3）

**主角与视角**
4. 专业/手艺视角：主角凭专门知识（法医/仵作/纸匠/律法）识真相，是手艺不是智力碾压。（现代法医→仵作）
5. 主角被卷入：案件/困境找上主角，被迫应对，非主动接案。（为洗冤被迫查案）
6. 观察者主角：主角看得见真相却无权处置，张力来自"看见而不能"。（去问艾丽丝的观察者）

**群像与关系**
7. 群像各藏秘密：嫌疑人/关系网每人藏一处不可告人，真相在秘密网里。（三权贵各藏秘密；身边女人各有故事）
8. 关系契约化：人物关系用明确规则/契约驱动，规则即冲突源。（约法三章）
9. 人物道德复杂：非纯善纯恶，对抗者与妥协者是一念之差。（双疯批互相折磨）

**世界与形态**
10. 架空但有质感：虚构朝代/世界免史实枷锁，但制度器物称谓须有时代质感。（大梁朝；架空标签 21597 次）
11. 标题双策略：雅致留白（危檐/既白/春夜宫词）或钩子直给（我在大梁当仵作/王爷亡妻竟是我自己），按类型择一。
12. 长篇连载强钩子：每章/每回末设因果钩，下章承接其果，强钩子＝高粘性。（风吹草动 416k 字/241 万阅读）

## 写作工作流

1. **定原创前提**：与用户确认题材（悬疑/公案/政治/言情/幻想）、主角手艺、核心反常物证、架空世界质感。前提必须原创，不得套用榜单作品的人/事。
2. **选技法配组**：按题材从十二条选 6-8 条作骨架。公案/政治小说默认配 1/2/4/5/6/7/9/10/12；言情默认配 1/3/8/9/12；生活悬疑默认配 6/7/1。
3. **搭因果钩链**：先立每章/每回末的因果钩与下章承接，转场由主角个人利害驱动，禁论断式拼接。
4. **逐场景起草**：场景/动作/声音起笔，禁"某某是某某"论断开篇；视角外→内两段式（前半旁人看动作，后半沉进人物独白）；完整自然语言句，禁电报体短句碎片。
5. **跑闸门**：每章/每回收工跑机械闸门＋人工审计（见下）。
6. **版权自检**：交稿前扫一遍，确认无榜单作品的受保护表达/人名/情节混入。

## 质量闸门

**机械闸门**（脚本，低自由度）：
```
python scripts/gate.py <file.md> --names <书名1,书名2> --max-short 5.0
```
检 CJK 字数、拉丁字母零、"——不"自我更正零、书名自指、短句（≤6 汉字）占比。退出码 0 为过。

**人工审计**（脚本兜不住，须对照）：电报体碎片、论断开篇、简历式起笔、穿帮预知（角色不得提前知道后文事件）、外→内视角是否落实、因果钩是否咬合、版权边界是否守住。

## 分层原则

本 skill 是**市场技法层**（跨类型通用方法）。若用户在写特定文体的长篇（如章回体、方言肌理、公版法律底本引用），应在技法层之上叠加自己的**文体契约层**（硬约束 + 专用闸门），两层互补不互替。
